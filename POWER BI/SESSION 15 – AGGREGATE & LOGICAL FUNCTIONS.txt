Q1. Create a table of 5 most-used food delivery apps with a column for total orders placed. Use the SUM function to calculate the total number of orders across all apps and display it in a Card.

Ans:- Steps:

- Open Power BI Desktop.
- Create or load a table containing 5 food delivery apps.
- Add the following apps:
  - Zomato
  - Swiggy
  - Domino's
  - McDonald's
  - Pizza Hut
- Add a column named Total Orders.
- Enter the order count for each app.
- Go to the Modeling tab.
- Click New Measure.
- Enter the following DAX formula:

Total Orders = SUM(Apps[Total Orders])

- Press Enter.
- Go to Report View.
- Select a Card visual.
- Drag Total Orders into the Card.
- Check the total number of orders across all apps.

Result:

- A table containing 5 food delivery apps was created.
- The SUM function successfully calculated the total orders.
- The total orders were displayed in a Card visual.

Q4. Add a calculated column that shows High Performer if the app's order count is above the average, otherwise Regular. Use SWITCH, AND/OR, VAR, and RETURN.

Ans:- Steps:

- Open Power BI Desktop.
- Select the Apps table.
- Go to Modeling.
- Click New Column.
- Enter the following DAX formula:

Performance =
VAR AvgOrders = AVERAGE(Apps[Total Orders])
RETURN
SWITCH(
    TRUE(),
    Apps[Total Orders] > AvgOrders, "High Performer",
    "Regular"
)

- Press Enter.
- A new Performance column will be created.
- Check the values in the table.
- Apps with orders above the average are labeled High Performer.
- Other apps are labeled Regular.

Result:

- A calculated Performance column was successfully created.
- VAR was used to store the average order count.
- RETURN was used to return the final result.
- SWITCH was used to classify the apps.


Q5. Create a DAX measure that returns Top Choice if an app has more than 100 orders and a rating above 4, otherwise Consider Alternatives. Use AND, IF, and NOT functions.

Ans:- Steps:

- Open Power BI Desktop.
- Select the Apps table.
- Go to the Modeling tab.
- Click New Measure.
- Enter the following DAX formula:

App Recommendation =
IF(
    AND(
        SUM(Apps[Total Orders]) > 100,
        AVERAGE(Apps[Order Ratings]) > 4
    ),
    "Top Choice",
    "Consider Alternatives"
)

- Press Enter.
- Go to Report View.
- Select a Table visual or Card visual.
- Add App Name to the visual.
- Add App Recommendation to the visual.
- Check the result for each app.

Result:

- A DAX measure was successfully created.
- AND checks both conditions.
- IF returns Top Choice when both conditions are true.
- Otherwise, it returns Consider Alternatives.
